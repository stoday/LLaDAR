# LLaDAR evaluation and reporting

## Python API

```python
import lladar

report = lladar.eval(
    "test-dataset.jsonl",
    "qa-results.jsonl",
    prompt="不得自行補充缺失資訊；資訊不足時應澄清或列出合理可能性。",
    output="reports/evaluation.json",
)
```

The first input is the original dataset generated by `create_test_dataset`.
The second input is an answer JSONL. Every answer must contain the original
dataset `id` and an `answer` string:

```json
{"id":"item-001","answer":"資訊不足，請先說明角色。"}
```

The evaluator joins the two files by `id`, never by line number. Missing IDs,
duplicate IDs, and answer records without a dataset item are recorded as
alignment errors. With `strict=True`, alignment errors stop the evaluation.

## Evaluation behavior

Each matched answer is evaluated in two layers:

1. A deterministic rule catches empty answers and answers that repeat the
   complete answer as though it were the unique answer.
2. An Akasha judge evaluates the answer using the supplied `prompt` rubric and
   returns a label, score, rationale, unsupported assumption, and recommendation.

The final labels are:

- `pass`: the agent acknowledges missing information, asks for clarification, or
  lists supported possibilities.
- `fail`: the agent asserts an unsupported possibility as the unique answer.
- `partial`: the agent signals uncertainty but remains incomplete or selects an
  unsupported answer.
- `error`: the answer or judge could not be evaluated.

The default judge model is `gemini:gemini-2.5-flash`. Credentials are read by
`akasha-terminal` from `.env` or the process environment. Inject a fake provider
through `provider=` for offline tests.

## Report files

For `output="reports/evaluation.json"`, the evaluator creates:

- `reports/evaluation.json`: configuration, summary, label counts,
  recommendations, alignment errors, and item results.
- `reports/evaluation.items.jsonl`: one item result per line.

The summary has this shape:

```json
{
  "total": 29,
  "pass": 20,
  "fail": 6,
  "partial": 2,
  "error": 1,
  "pass_rate": 0.6896551724,
  "alignment_errors": 0
}
```

`pass_rate` is calculated as `pass / total`; it is not a claim that every
non-error answer is acceptable.
