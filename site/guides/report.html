Create an evaluation report

Turn the saved evaluation results into a report that readers can check.

Basic command

lladar report evaluation.json --output report.md

The positional EVALUATION points to the previous evaluation JSON. --output names the Markdown report to create.

What the report includes

  • What was tested and the overall result.
  • Per-question judgments and their reasons.
  • How the totals were calculated from the saved results.
  • The scope and limits of this run.

Review dataset coverage and token usage

lladar report dataset.jsonl.generation.json --output dataset-coverage.md

Use the generation sidecar to review independently inventoried facts and question coverage. From v0.17.0, when the sidecar contains token_usage, this report also includes the saved input/output totals, per-stage usage and accounting limits. Rendering this saved coverage report with the default method does not make another model call.

The original dataset command also writes dataset.jsonl.operation.md, with the work-session token total and usage added by that invocation. Resume keeps the cumulative total; a missing usage record is unknown, not zero. Older sidecars without token records cannot provide retrospective totals. These figures describe dataset generation; see the fields and limits before comparing them with a provider bill.

Use it to improve the Agent

Do not treat the report as only a score. Group failed questions: is the source material unclear, did the Agent ignore a rule, or did the test miss an important real-world situation? Improve the relevant part, then run the same workflow again.

Use a custom report Skill

A SKILL.md can request your team's sections, tone, or review fields. The individual results and calculated totals remain available so readers can trace a conclusion back to the evidence.

lladar report evaluation.json --skill skills/compliance-summary --output report.md

Situation reports

lladar report evaluation.json --output report.md renders situation counts and cited turn evidence without another model call by default. An optional --skill DIRECTORY adds narrative but does not change the saved judgments or totals. See the situation artifacts.
