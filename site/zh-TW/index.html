精簡的 Agent 評估流程

問題、預期答案、真實回應，接著由 Agent 協助評估並產生可重現的報告。

格式建立執行評估報告

固定三欄 record

{"question":"台灣的首都是哪座城市？","expected_answer":"台北","actual_response":null}

JSONL 每一筆固定只有這三個欄位，不再有 schema 版本或相容模式。

一、建立資料集

lladar create test-dataset --knowledge ./knowledge --output dataset.jsonl

模型會針對每個採用的知識片段，建立一個有來源依據的問題與預期答案。

二、執行目標 Agent

lladar run-agent dataset.jsonl --project ../my-agent --output responses.jsonl

Runner 只填入 actual_response，不做評分；執行錯誤會記錄在 responses.jsonl.run.json。

三、評估

lladar eval responses.jsonl --prompt "評估正確性與完整度。" --output evaluation.json

評估 Agent 先固定適合的維度，再逐筆判讀。所有筆數、分佈、比率與描述統計都由 Python 計算。

四、產生報告

lladar report evaluation.json --output report.md

報告包含確定性表格、有證據邊界的解讀、限制與逐筆附錄。
