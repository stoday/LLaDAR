開始使用

用範例客服 Agent 跑完一次完整測試

這個範例會測試一個已存在的客服 Agent：從客服政策出題、讓 Agent 回答、檢查回答，到輸出報告。

開始前

  • Python 3.11 或 3.12。
  • 已設定可用的 LLaDAR provider。它會用在產生題目和評估回答。
  • 這個範例 Agent 只使用 Python 標準函式庫，不必另外安裝 Agent 的相依套件。

1. 安裝 LLaDAR

先取得專案並以可編輯模式安裝。下面的指令要在你想放置專案的目錄執行。

git clone https://github.com/stoday/LLaDAR.git
cd LLaDAR
python -m pip install -e .

2. 用客服政策建立題目

knowledge.md 是範例客服 Agent 應遵守的規則。這個指令會根據它建立測試資料，並寫入 artifacts/support-demo/dataset.jsonl。

lladar create test-dataset --knowledge examples/support-demo-agent/knowledge.md --output artifacts/support-demo/dataset.jsonl

想知道測試資料包含什麼，請看建立測試資料指南。

3. 讓範例 Agent 回答題目

LLaDAR 會讀取範例專案，找出如何把問題送給 Agent，先試跑確認，再執行所有題目。--no-interactive 表示使用已找到的做法直接執行，不在中途要求你選擇。

lladar run-agent artifacts/support-demo/dataset.jsonl --project examples/support-demo-agent --output artifacts/support-demo/responses.jsonl --no-interactive

結果會寫入 responses.jsonl；responses.jsonl.run.json 記錄執行入口與狀態。詳情請看執行 Agent 指南。

4. 檢查回答並產生報告

先逐題比較預期答案和 Agent 的回答，再把結果寫成報告。

lladar eval artifacts/support-demo/responses.jsonl --output artifacts/support-demo/evaluation.json
lladar report artifacts/support-demo/evaluation.json --output artifacts/support-demo/report.md

跑完後會看到什麼？

檔案用途
dataset.jsonl問題、預期答案與尚未填寫的實際回答；來源記錄存於 .generation.json。
responses.jsonl每題的實際回答；.trials.jsonl 記錄各次試跑。
responses.jsonl.run.json採用的執行入口與執行狀態。
evaluation.json每一題的檢查結果和總計。
report.md方便人閱讀和分享的結果報告。

試跑成功只代表 LLaDAR 真的能透過 Agent 對外提供的入口送出問題；要知道回答好不好，請看後面的逐題評估和報告。

接著試試多輪情境

若要觀察一段對話中的行為，而且沒有必備知識文件，請照多輪情境的可複製範例操作：建立設定、校準 session adapter、保存對話，再依整段對話評估。
