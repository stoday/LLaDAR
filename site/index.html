User guide

A simple Agent evaluation pipeline

Question, expected answer, actual response—then Agent-assisted evaluation and a reproducible report.

FormatCreateRunEvaluateReport

One three-field record

{"question":"What is Taiwan's capital?","expected_answer":"Taipei","actual_response":null}

Every JSONL row has exactly these fields. There are no schema versions or compatibility modes.

1. Create a dataset

lladar create test-dataset --knowledge ./knowledge --output dataset.jsonl

The model creates one source-grounded question and expected answer per accepted chunk.

2. Run the target Agent

lladar run-agent dataset.jsonl --project ../my-agent --output responses.jsonl

The runner fills only actual_response. It records execution failures in responses.jsonl.run.json and does not score answers.

3. Evaluate

lladar eval responses.jsonl --prompt "Assess correctness and completeness." --output evaluation.json

The evaluator Agent freezes useful dimensions and judges each completed response. Python calculates all counts, distributions, rates, and descriptive statistics.

4. Report

lladar report evaluation.json --output report.md

The report combines deterministic tables, an evidence-bounded interpretation, limitations, and a record-level appendix.
